### 1. Architecture Overview

NEXUS is engineered as a high-performance, static Single Page Application (SPA) designed to be hosted on AWS Amplify Hosting’s global Content Delivery Network (CloudFront edge stratum).

```
[ Developer Local Machine ]
           │
           ▼ (git push origin main)
[ GitHub Repository: ASingha165/Nexus ]
           │
           ▼ (Webhook trigger)
[ AWS Amplify Hosting CI/CD Pipeline ]
     ├── Step 1: Clone repo & npm ci
     ├── Step 2: npm run build (tsc -b && vite build)
     └── Step 3: Publish "dist/" artifacts to AWS Global CDN
           │
           ▼
[ Global Edge CDN / CloudFront ] ──► Public Visitors (HTTPS)
```

* **No Backend Server Required**: Zero ongoing compute or database running costs; static edge distribution.
* **Automatic SSL/TLS**: AWS Certificate Manager (ACM) provisions a free managed SSL certificate.
* **Continuous Deployment**: Every verified commit pushed to `main` automatically triggers an incremental build and global deployment.

### 2. Verified Build Configuration (`amplify.yml`)

The repository includes an authoritative `amplify.yml` at the project root:

```yaml
version: 1
frontend:
  phases:
    preBuild:
      commands:
        - npm ci
    build:
      commands:
        - npm run build
  artifacts:
    baseDirectory: dist
    files:
      - '**/*'
  cache:
    paths:
      - node_modules/**/*
```

#### Build Phases Explained:
* **`preBuild`**: Executes `npm ci` to install exact dependencies from `package-lock.json` in clean CI environments.
* **`build`**: Executes `npm run build`, which runs `tsc -b` for strict type checking followed by `vite build` producing the production-ready assets in `dist`.
* **`artifacts`**: Specifies `dist` as the output directory.
* **`cache`**: Caches `node_modules` across builds, reducing subsequent build times to under 1 minute.

### 3. SPA Routing & Rewrite Rules

In client-side single-page applications using `react-router-dom`, direct navigation or page refreshes on subpaths (e.g. `/decision-lab`, `/constellation`) require a rewrite to `/index.html` with an HTTP status of `200`.

#### Configuration in AWS Amplify Console:
1. In the AWS Amplify Console, navigate to **Hosting** > **Rewrites and redirects**.
2. Verify or add the standard Single Page App rewrite rule:

| Source address | Target address | Type | Country code |
| :--- | :--- | :--- | :--- |
| `</^[^.]+$|\.(?!(css|gif|ico|jpg|js|png|txt|svg|woff|woff2|ttf|map|json)$)([^.]+$)/>` | `/index.html` | `200 (Rewrite)` | - |

*(Note: The repository also bundles `public/_redirects` which copies to `dist/_redirects` automatically for static web hosts supporting Netlify/Amplify redirect formats).*

### 4. Step-by-Step GitHub Connection Procedure

To connect the repository to AWS Amplify Hosting:

1. **Log in to AWS Management Console**:
   * Open the **AWS Management Console** and navigate to **AWS Amplify**.
2. **Create New App**:
   * Click **Deploy an app** or **Host web app**.
   * Select **GitHub** as the source code provider and click **Next**.
3. **Authorize GitHub**:
   * Select the repository: `ASingha165/Nexus`.
   * Select the branch: `main`.
4. **App Settings & Build Specification**:
   * Amplify will automatically detect `amplify.yml` in the repository root.
   * Verify that **App name** is set to `NEXUS` (or `nexus-portfolio`).
   * Verify **Build settings** confirms `baseDirectory: dist`.
5. **Review and Deploy**:
   * Click **Save and deploy**.
   * Amplify will initiate the Provision, Build, and Deploy lifecycle.
   * Upon completion, Amplify will assign a default public URL (e.g. `https://main.d123456789.amplifyapp.com`).

### 5. Custom Domain Configuration (Optional)

To attach a custom domain (e.g. `nexus.ankitsingha.dev` or `ankitsingha.me`):
1. In the Amplify Console, navigate to **Hosting** > **Custom domains**.
2. Click **Add domain** and enter your registered domain.
3. Configure the DNS CNAME records generated by Amplify in your DNS provider (e.g. Route 53, Cloudflare, GoDaddy).
4. ACM will automatically validate domain ownership and issue an SSL/TLS certificate.

### 7. Troubleshooting Guidance

| Symptom | Probable Cause | Corrective Action |
| :--- | :--- | :--- |
| **Build fails during `npm ci`** | Lockfile mismatch or node version mismatch. | Verify Amplify build image is set to Node 20+; run `npm ci` locally to verify lockfile integrity. |
| **Page refresh returns 404** | Missing SPA rewrite rule. | Add the 200 rewrite rule in Amplify Console under **Rewrites and redirects**. |
| **Broken assets / 404 on CSS/JS** | Incorrect base URL path. | In `vite.config.ts`, verify `base: '/'` (default). |
| **Fonts or Icons Missing** | Network/CORS block on external fonts. | Google Fonts and Material Symbols preconnected in `index.html`. |
